accuracy claim. Local and hosted checks do not prove provider, tenant, or pilot
behavior.

## Configuration boundary

The Community default is metadata/signals-only storage. A deployment that
enables stored message bodies must configure the Business storage mode and its
encryption key. Production deployments must also set the storage DSN to a
writable persistent path or PostgreSQL; the image filesystem is read-only.
